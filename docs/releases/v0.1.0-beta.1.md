# v0.1.0-beta.1 外测发布说明

发布日期：2026-08-27

## 发布定位

本版本为闽大铸件 MES 的第一版外部测试基线，覆盖管理端、API 和微信小程序三端。线上环境用于业务流程验证，不作为最终生产验收版本。

## 主要功能

- 基础资料：部门、用户、角色权限、客户、供应商、物料和字典管理。
- 模具业务：模具开发、收发货、试产/量产/评判、模具及多芯盒建档。
- 生产建模：车间产线、班组、设备、材质牌号、熔炼配方、铸造 BOM、工序和工艺路线。
- 生产执行：生产工单、节点化任务下达、制芯、熔炼与转运、造型下芯、合型浇注、落砂清理、成品终检。
- 移动执行：小程序端模具跟单及制芯、熔炼、造型、浇注、落砂清理、终检报工。
- 权限体系：菜单、数据列表、按钮、数据范围和小程序菜单权限。

## 关键业务约束

- 生产工单锁定创建时的 BOM 与工艺路线版本，后续主数据停用不影响历史工单执行。
- 熔炼任务由工单工艺路线节点手工释放，制芯未完成只提示，不做硬拦截。
- 同一工单的多个熔炼节点独立释放，炉次分配绑定具体工艺路线节点。
- 下游任务由上游报工数据驱动，前端不制造本地任务或假成功状态。
- 所有写操作以后端权限、数据范围、状态和版本校验为最终边界。

## 数据升级

发布前必须备份 PostgreSQL。代码同步后按以下顺序执行：

1. `npm --prefix apps/api run prisma:generate`
2. `npx --prefix apps/api prisma db push`
3. `npm --prefix apps/api run seed:shake-clean-equipment-types`
4. `npm --prefix apps/api run backfill:shake-batches`
5. `npm --prefix apps/api run seed:final-inspection-warehouses`
6. `npm --prefix apps/api run backfill:inspection-batches`
7. `node apps/api/scripts/backfill-work-order-melt-release.mjs`

任一步骤失败时停止发布，不启动新 API。
