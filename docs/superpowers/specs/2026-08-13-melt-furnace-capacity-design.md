# 合炉排产熔炼设备与单炉剩余产能设计

## 背景

合炉排产页面的“目标熔炼设备”下拉为空。当前设备档案中的熔炼设备能力单位为 `吨/炉`，而排产容量换算仅接受 `kg`、`千克`、`t`、`吨`，导致有效设备在组装排产选项时被静默过滤。

本阶段不引入工厂日历、设备节拍或班次累计产能。产能统一按单炉容量计算，为后续时间段产能和班次产能保留扩展空间。

## 业务规则

1. 目标熔炼设备来源于当前材质牌号已生效配方所绑定的启用设备。
2. 设备必须配置正数容量和受支持的重量容量单位，否则不进入排产候选项。
3. 支持以下等价容量单位：
   - 千克类：`kg`、`千克`、`kg/炉`、`千克/炉`
   - 吨类：`t`、`吨`、`t/炉`、`吨/炉`
4. 单炉目标铁水重量为所有已选生产工单的“本炉分配件数 × 单件浇注毛重”之和。
5. 单炉剩余产能：`设备单炉容量（kg）- 单炉目标铁水重量（kg）`。
6. 剩余产能小于 0 时禁止生成熔炼任务；等于 0 时允许生成。
7. 后端创建炉次时重新计算目标重量和设备容量，不信任前端传入的容量、剩余量或利用率。
8. 已存在的其他炉次不占用本炉容量。设备时间冲突、每日炉数和班次累计产能不属于本阶段范围。

## 后端设计

### 容量换算

扩展生产计算模块的 `capacityToKg`，规范化单位中的空格和大小写，并支持带 `/炉` 后缀的熔炼容量单位。其他设备使用的 `件/班`、`kg/h`、`吨/小时` 等速率单位不作为单炉熔炼设备容量，继续拒绝进入合炉排产。

### 排产选项

`GET /admin/production/melt-pool/options?materialGradeCode=...` 返回：

- 与材质已生效配方关联的可用熔炼设备；
- 统一换算后的 `capacityKg`；
- 原始能力值和单位，便于前端解释数据；
- 与设备车间匹配的启用班组。

若当前材质没有可用设备，接口正常返回空设备列表，并提供可诊断原因；前端展示明确空状态，不再只显示空白下拉。

### 创建校验

`POST /admin/production/heat-orders` 在可串行化事务中：

1. 重新读取工单及有效分配；
2. 计算当前炉次目标铁水重量；
3. 读取并换算目标设备单炉容量；
4. 校验目标重量不超过单炉容量；
5. 校验配方、材质、设备和执行班组关系；
6. 通过后创建炉次和分配明细。

超容量返回业务错误，错误信息包含设备名称、单炉容量、目标重量和超出重量。

## 管理端交互

1. 目标熔炼设备下拉显示：`设备名称（容量）`，容量统一以吨展示并保留合适小数。
2. 没有候选设备时，下拉显示“当前材质暂无可用熔炼设备，请检查已生效配方和设备容量配置”。
3. 排产凑吨计算器展示：
   - 已选工单数；
   - 分配件数；
   - 目标铁水；
   - 单炉容量；
   - 剩余产能；
   - 单炉利用率。
4. 剩余产能大于等于 0 时正常展示；小于 0 时标红，并禁用“生成熔炼任务”。
5. 切换设备时清空配方和班组，重新按设备过滤可用配方与同车间班组。

## 测试范围

### 计算测试

- `1 吨/炉` 换算为 `1000 kg`。
- `2200 kg/炉` 换算为 `2200 kg`。
- 原有 `t / 吨 / kg / 千克` 保持兼容。
- `件/班`、`kg/h` 等非单炉重量单位继续报错。

### 接口测试

- 材质关联的启用配方绑定 `吨/炉` 设备时，排产选项能返回该设备。
- 目标重量小于、等于单炉容量时可创建炉次。
- 目标重量超过单炉容量时后端拒绝。
- 配方未绑定设备、设备停用、设备容量无效、班组不属于设备车间时均拒绝。

### 页面验证

- 目标熔炼设备可选择现有 `1T中频感应炉` 和 `2T中频感应炉`（以当前材质配方绑定为准）。
- 选择设备和工单后，剩余产能与利用率实时更新。
- 超容量时按钮禁用，减少分配件数后恢复。

## 后续扩展

在工厂日历、班次和设备标准熔炼周期完成后，可在本设计上增加“时间段占用”和“班次剩余炉数”。该扩展应新增独立的设备排程能力，不改变本阶段单炉容量的定义。
