# 熔炼配方管理设计

日期：2026-08-12  
范围：一期配方主档、目标化学成分、标准配料、克隆与状态管理

## 1. 目标与边界

熔炼配方是铸造熔炼工序的标准“冶金食谱”。一期建立材质牌号与熔炼配方的 1:1 或 1:N 关系，将目标成分、适用熔炼设备、标准原料及辅料用量持久化，并支持草稿、生效、停用和克隆。

本期不实现审批流、成本核算、库存校验、投料执行、炉批管理、化验自动判定和版本差异比较。后续炉批只能引用已生效配方及其版本快照。

## 2. 现有功能复用

- 不新增菜单；继续使用“工艺管理 → 熔炼配方”。
- 路由保持 `/dashboard/model/recipe`。
- 列表复用 `ResizableTable`，操作列固定右侧并使用 `TableActions`。
- 新增、编辑、查看复用材质牌号的大弹窗交互、表单布局和明细录入风格。
- 所有下拉选项来自真实接口，不使用前端 mock。
- 所有保存、克隆、状态变更和删除均由后端持久化并返回真实结果。

## 3. 数据关系

```text
MaterialGrade 1 ── N MeltRecipe
Furnace       N ── N MeltRecipe
MeltRecipe    1 ── N RecipeTargetElement
MeltRecipe    1 ── N MeltRecipeItem
Product       1 ── N MeltRecipeItem
MeltRecipe    N ── 1 sourceRecipe
User          1 ── N MeltRecipe（创建人）
```

### 3.1 MeltRecipe

- `code`：业务编码，唯一。
- `name`：配方名称。
- `materialGradeCode`：关联材质牌号编码。
- `version`：版本号，默认 `V1.0`。
- `baseWeightKg`：配方基准重量，默认 `1000 kg`。
- `status`：`DRAFT / ACTIVE / DISABLED`。
- `sourceRecipeCode`：克隆来源配方编码，可为空。
- `createdByUserId`：创建人，取当前登录用户。
- `remark`：备注。
- `createdAt / updatedAt`：系统时间。

### 3.2 RecipeApplicableFurnace

多对多关联配方与设备配置中的具体熔炼设备。创建和编辑配方时仅允许选择熔炼车间的启用设备，并支持多选。

设备配置现有“允许材质”字段从管理端页面移除，后端不再把它用于配方或材质校验。历史字段和数据暂时保留，避免破坏已有数据库。

### 3.3 RecipeTargetElement

- `recipeCode`：关联配方。
- `elementName`：元素名称。
- `minValue / maxValue`：目标成分上下限。
- `unit`：默认 `%`。
- `remark`：控制要点。
- 同一配方内元素名称唯一。

选择材质牌号时自动复制该牌号的化学成分明细作为配方快照。复制后允许自由编辑，一期不限制是否超出牌号标准范围。材质牌号后续变化不覆盖历史配方目标值。

### 3.4 MeltRecipeItem

- `recipeCode`：关联配方。
- `itemCode`：关联物料管理中的物料编码。
- `materialCategory`：`RAW / RETURN / ADDITIVE`，用于比例校验和显示。
- `ratio`：投料比例，原材料和回炉料使用。
- `quantity`：标准用量 kg。
- `unit`：默认 `kg`。
- `remark`：备注。

物料选择范围只包含物料类型树中一级类型为“原材料”的物料及其下级类型。物料名称和类型通过 Product relation 返回，不在配方明细重复维护。

## 4. 列表页

### 4.1 查询条件

- 材质牌号：下拉，可按编码或名称搜索。
- 配方编码/名称：输入框，模糊查询。
- 适用炉型：下拉，读取启用的熔炼设备。
- 配方状态：全部、草稿、已生效、已停用。
- 查询按钮刷新当前条件下的真实接口数据。

### 4.2 列表字段

- 配方编码
- 配方名称
- 材质牌号
- 适用炉型
- 版本号
- 基准重量
- 状态
- 创建人
- 更新时间
- 操作

列表继续支持拖动列宽、横向滚动、固定右侧操作列和列宽记忆。

### 4.3 操作显示

- 草稿：查看、编辑、复制；有删除权限时删除进入“更多”。
- 已生效：查看、复制、停用。
- 已停用：查看、复制。
- 操作按钮按当前登录用户实际授权计算，最多直接展示三个，超过三个进入“更多”。

## 5. 新增、编辑与查看弹窗

弹窗沿用材质牌号页面样式，宽度适配三段式明细，内部可滚动。区块不使用嵌套卡片，采用标题和分隔线组织。

### 5.1 基本信息

- 配方编码：新增时系统生成 `REC-YYYYMMDD-三位流水号`，只读。
- 配方名称：必填。
- 材质牌号：必填，下拉选择。
- 适用炉型：必填，多选具体熔炼设备。
- 版本号：默认 `V1.0`，草稿可编辑。
- 基准重量：默认 `1000 kg`，必须大于 0。
- 备注：选填。

### 5.2 目标化学成分

选择或更换材质牌号时，如果当前成分区为空则自动带入牌号成分；如果已有人工编辑内容，前端先确认是否覆盖。

明细列为：元素、目标下限、目标上限、单位、备注/控制要点、删除。支持增加和删除明细行。

### 5.3 标准配料与辅料

明细列为：物料编码、物料名称、物料类型、配料分类、投料比例、标准用量、单位、备注、删除。

- 原材料、回炉料：填写比例，标准用量自动按 `baseWeightKg × ratio ÷ 100` 计算。
- 辅料/合金：比例可空，直接填写标准用量。
- 修改基准重量或比例时重新计算自动用量。

### 5.4 底部操作

- 新增或编辑草稿：取消、保存为草稿、提交生效。
- 查看：关闭。
- 已生效和已停用：表单全部只读。

## 6. 状态与校验

### 6.1 草稿

保存草稿只要求配方名称、材质牌号、适用炉型、版本和有效基准重量。目标成分及配料可以暂不完整。

### 6.2 提交生效

提交生效时必须满足：

- 至少一个目标化学成分。
- 至少一条配料。
- 原材料与回炉料的投料比例合计为 `100%`。
- 目标上下限、比例和用量不能为负数。
- 目标下限不能大于目标上限。
- 每个配料物料和目标元素在同一配方内不能重复。

### 6.3 生效与停用

- 已生效配方禁止编辑和删除。
- 已生效配方可停用，停用后禁止恢复和编辑。
- 已停用配方只允许查看和克隆。
- 同一材质牌号允许存在多个已生效配方，用适用炉型和版本区分。
- 后端必须执行状态约束，前端隐藏按钮只用于改善交互。

## 7. 配方克隆

点击复制后弹窗确认：“确定基于 [配方名称] 创建新配方吗？”

确认后，后端在同一事务中复制：

- 材质牌号
- 适用炉型
- 基准重量
- 目标成分
- 配料明细
- 备注

新记录规则：

- 编码按当日流水生成，例如 `REC-20260812-001`。
- 名称为“原配方名称-副本”，允许后续修改。
- 版本为 `V1.0`。
- 状态为草稿。
- `sourceRecipeCode` 保存原配方编码。
- 创建人保存执行克隆的当前用户。

编码生成必须在数据库事务内处理并防止并发重复。

## 8. 权限

保留：

- `model.recipe.view`
- `model.recipe.create`
- `model.recipe.edit`
- `model.recipe.delete`

新增：

- `model.recipe.clone`
- `model.recipe.activate`
- `model.recipe.disable`

列表、弹窗按钮和后端接口分别按对应权限控制。系统管理员默认拥有全部权限；普通角色默认不自动获得新增权限。

## 9. API

- `GET /admin/modeling/recipes`：分页/查询列表。
- `GET /admin/modeling/recipes/:code`：详情。
- `POST /admin/modeling/recipes`：保存草稿。
- `PUT /admin/modeling/recipes/:code`：编辑草稿。
- `POST /admin/modeling/recipes/:code/activate`：提交生效。
- `POST /admin/modeling/recipes/:code/clone`：克隆配方。
- `POST /admin/modeling/recipes/:code/disable`：停用配方。
- `DELETE /admin/modeling/recipes/:code`：仅删除草稿。
- `GET /admin/modeling/recipe-options`：材质牌号、熔炼设备、原材料物料选项。

所有接口继续返回统一 `{ code, message, data }`。新增、编辑和克隆使用事务保存主表与全部关系明细，任何明细失败时整体回滚。

## 10. 错误处理

- 编码冲突：后端重新取流水并重试，最终失败时返回明确错误。
- 非草稿编辑或删除：返回 400 和当前状态不可操作说明。
- 无权限：返回 403。
- 关联材质、设备或物料不存在：返回 400，不保存部分数据。
- 生效校验失败：返回具体字段或合计错误，不改变原草稿状态。
- 被后续炉批引用后的配方，未来即使为草稿也应禁止删除；一期尚无炉批关系，预留删除检查位置。

## 11. 测试范围

- 材质牌号选择后目标元素自动带入且可自由编辑。
- 适用炉型只返回熔炼车间的启用设备，并支持多选。
- 配料物料只返回“原材料”一级类型及其子类型。
- 草稿允许不完整保存，生效时严格校验。
- 基准重量和比例变化正确计算标准用量。
- 克隆复制全部明细并生成新编码、名称、版本、状态、来源和创建人。
- 已生效禁止编辑/删除，允许停用；已停用只允许查看/克隆。
- 前端按钮与后端权限守卫一致。
- 刷新后所有数据仍存在，不出现本地态或假成功。
