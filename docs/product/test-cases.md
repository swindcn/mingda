### 角色权限自动化测试

脚本位置：

```bash
scripts/test-permissions.mjs
```

执行命令：

```bash
npm run test:permissions
```

默认测试目标：

- API：`http://124.223.2.193/api`
- 管理员：`admin / 13665068911`
- 受限用户：`13600003333 / 13600003333`
- 受限角色：`生产管理`

可通过环境变量覆盖：

```bash
MINGDA_API_BASE_URL=http://127.0.0.1:3000/api \
MINGDA_LIMITED_USERNAME=13600003333 \
MINGDA_LIMITED_PASSWORD=13600003333 \
npm run test:permissions
```

自动化覆盖：

- 角色可保存并返回多个数据行权限。
- 受限用户重新登录后返回多个 `dataScopes`。
- 无基础资料权限时访问用户列表返回 403。
- 本人数据范围不返回历史全量建模数据。
- 只有车间数据列表权限时，新增车间接口返回 403。
- 受限用户创建数据后，只能看到自己创建的数据。
- 测试结束后恢复角色原配置，并删除临时车间数据。
