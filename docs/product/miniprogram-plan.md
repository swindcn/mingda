# 微信小程序端规划

## 定位

小程序端面向外部协同人员，优先服务模具供应商和内部移动审批/跟单场景。

当前 Figma Make 参考：

```text
https://www.figma.com/make/zo9WgXvpNGadzIcIy9ImOm/%E5%BE%AE%E4%BF%A1%E5%B0%8F%E7%A8%8B%E5%BA%8F%E7%99%BB%E5%BD%95%E9%A1%B5
```

已确认可读取的 Figma Make 模块：

- 登录页
- 首页
- 待办列表
- 模具开发列表
- 模具开发详情
- 图纸确认
- 发货
- 收货
- 试模生成
- 批量生产
- 模具评判

## 工程选择

当前初始化为微信原生小程序 + TypeScript：

```text
apps/miniprogram
```

选择原因：

- 先满足微信小程序交付
- 工程轻量，便于快速对齐业务流程
- 与后端 API 对接直接
- 后续如需要多端复用，可再评估 Taro / uni-app

## 一期页面

- 登录页：账号密码登录，记住密码
- 首页：待办数量、模具开发数量、快捷入口
- 待办页：图纸确认、发货、收货、模具评判等任务
- 模具开发列表：按编号、客户、产品搜索
- 模具开发详情：查看基础信息和协同动作入口
- 提交页：发货、收货、试模生成、批量生产、模具评判

## 接口对接计划

第一批接入：

- 登录
- 当前用户
- 待办列表
- 模具开发列表
- 模具开发详情

第二批接入：

- 图纸确认
- 发货提交
- 收货提交
- 试模生成提交
- 批量生产提交
- 模具评判提交

## 业务规则

- 小程序端不显示管理后台字段配置。
- 小程序端只展示当前用户有权限处理的数据。
- 供应商确认图纸后，管理端开发进度应显示确认人和确认时间。
- 发货必须上传发货图片，并填写快递单号。
- 收货必须上传收货图片。
- 试模生成、批量生产可多次提交，管理端按次数显示记录。
- 模具评判可标识是否开发完成。
