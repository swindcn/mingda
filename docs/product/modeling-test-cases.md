覆盖生产建模模块的后端权限、真实 Prisma relation、多值明细表映射、引用删除限制和基础 CRUD。

## 前置条件

- API 服务可访问：`http://124.223.2.193/api`
- 管理员账号：`admin / 13665068911`
- PostgreSQL 已执行最新 Prisma schema。
- 系统中至少有一个内部员工可用于班组成员测试。

## 自动化验证点

- 所有新增接口必须返回统一 `{ code, message, data }`。
- 无权限用户访问建模接口必须返回 `403`。
- 不存在的外键引用必须返回 `400`。
- 多值字段必须从真实明细表映射回接口字段。
- 被引用主数据不能删除。
