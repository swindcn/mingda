# 闽大铸件

闽大铸件是面向铸件生产企业的业务管理与生产协同系统。系统当前已包含管理端 Web、后端 API、PostgreSQL 数据库和微信小程序端，重点覆盖基础资料、组织权限、模具开发协同、生产建模、工艺管理以及供应商小程序协同。

## 项目结构

```text
apps/
  admin/          管理端 Web 应用，React + TypeScript + Vite + Ant Design
  api/            后端服务，NestJS + Prisma + PostgreSQL
  miniprogram/    微信原生小程序端，TypeScript
packages/
  shared/         共享类型、常量、工具函数
  ui/             管理端通用 UI 组件
  api-client/     接口请求 SDK
docs/
  product/        产品规划、业务流程、测试用例和上下文记录
  design/         设计稿说明、页面清单
  api/            接口文档和后端规划
scripts/          项目脚本
```

## 已完成能力

### 管理端基础能力

- 登录鉴权：账号密码登录，登录后返回当前用户、角色、菜单权限、数据权限和字段权限。
- 后台布局：左侧菜单、顶部当前用户展示、主内容区独立滚动。
- 页面标准：数据列表统一支持查询刷新、列宽拖拽、横向滚动、固定右侧操作列。
- 操作标准：列表操作按钮按当前用户实际权限过滤；超过 3 个操作时自动进入“更多”下拉。
- 图片标准：上传后以方形缩略图横向展示，点击可预览大图。
- 路由保护：管理端子页面需要登录；生产建模、模具业务等页面按权限进入。

### 组织、用户与权限

- 部门管理：支持层级部门新增、编辑、删除；部门树以 `闽大铸件` 为根组织。
- 第三方同步配置：部门和用户同步预留钉钉、企业微信、飞书配置入口。
- 用户管理：支持员工、供应商、客户、超管等用户类型。
- 用户同步规则：手机号作为唯一标识；手机号相同覆盖用户资料，不同则新增。
- 用户回收站：删除用户进入回收站，禁用账号；超管不能直接删除。
- 用户部门关系：新增用户时组织固定为 `闽大铸件`，所属部门来自真实部门树。
- 角色权限：支持菜单权限、操作权限、数据范围、字段权限和授权用户。
- 数据权限设计：业务数据归属按数据发起人所属部门判断，角色可控制本人、本部门、本部门及下级、组织、自定义部门范围。

### 基础资料

- 客户管理：维护客户编码、名称、联系人、电话、地址。
- 供应商管理：维护供应商编码、名称、联系人、电话、地址。
- 物料管理：原“产品管理”已统一改为“物料管理”，维护物料编码、名称、规格、单位、类型、来源、价格、库存和产能。
- 字典设置：支持模具类型、物料单位、物料类型、岗位信息、车间类型等字典维护。

### 模具开发

- 模具开发下达：选择客户、物料、模具类型、供应商、跟单人、客户告知时间、期望完成时间并上传图纸附件。
- 模具开发列表：支持按状态查看进行中、已完成、已中止等数据。
- 模具开发详情：展示下达信息、附件缩略图、流程时间线、过程记录和操作按钮。
- 流程节点：
  - 开发下达
  - 供应商图纸确认
  - 供应商发货
  - 收货确认
- 过程记录：
  - 试模记录，可多次提交并按一次、二次等显示
  - 量产记录，可多次提交并按一次、二次等显示
  - 模具评判记录，支持评判结果、是否开发完成、评判理由
  - 中止开发记录，保留已发生的过程数据
- 状态规则：
  - 下达到确认前：待确认
  - 确认后到发货前：待发货
  - 发货后到收货前：待收货
  - 收货后到试模/量产前：待试产
  - 有试模、量产或评判数据：试产中
  - 评判选择开发完成：已完成
  - 中止开发：已中止
- 操作限制：
  - 已完成后不再允许试模、量产、评判和中止
  - 已中止后不再允许图纸确认、发货、收货、试模、量产和评判
  - 只有已中止的模具开发单可以删除

### 生产建模

生产建模模块用于建立后续排产、报工、质检所需的主数据。

- 车间与产线：维护车间、产线，车间下可展开查看产线。
- 班组配置：维护班组、组长和班组成员，成员来自内部员工。
- 设备配置：维护熔炼炉等关键设备，支持允许熔炼材质配置。
- 工厂日历：维护工作日、休息日、节假日和启用班次。
- 班次主档：维护班次编码、名称、开始时间、结束时间和跨日标识。
- 动态排班表：月历视图，支持按车间查看、单日排班维护和一键生成排班。

### 工艺管理

工艺相关模块已归类到“工艺管理”菜单。

- 材质牌号：维护材质编码、名称、执行标准、元素红线。
- 熔炼配方：关联材质牌号，维护版本和配料明细。
- 工艺路线：关联物料，维护工艺路线和工序步骤。
- 缺陷代码库：维护缺陷编码、名称、分类和易发工序。

### 模具与工装档案

- 模具档案：维护模具编码、名称、关联物料、型腔数、寿命上限、已用寿命、状态。
- 芯盒档案：维护芯盒编码、名称、关联模具、型腔数、寿命上限、已用寿命、状态。

### 微信小程序端

- 登录：接入正式后端账号密码登录，账号使用手机号。
- 首页：展示待办事项和功能入口。
- 模具开发列表：卡片式展示当前用户可见的模具开发任务，支持下拉刷新和状态页签。
- 模具开发详情：展示任务字段、下达附件、收发货记录、开发记录和操作按钮。
- 供应商协同：
  - 供应商员工只能查看所属供应商的模具开发任务
  - 待确认时生成图纸确认待办
  - 确认后生成发货待办
  - 发货支持多图、拍照、快递单号填写
- 跟单人协同：
  - 收货待办生成给跟单人
  - 收货后可提交试模、量产、模具评判
  - 试模和量产分别上传产品图片、破坏性检测图片
- 移动端限制：小程序端不提供编辑和中止功能。

## 功能关系

```text
组织部门
  └─ 用户
      ├─ 角色权限
      │   ├─ 菜单/操作权限
      │   ├─ 数据范围权限
      │   └─ 字段权限
      └─ 业务数据归属

客户 / 供应商 / 物料
  └─ 模具开发单
      ├─ 跟单人：内部员工
      ├─ 供应商：供应商员工在小程序处理确认和发货
      ├─ 附件：图纸、产品图片、发货/收货图片
      ├─ 固定流程：下达 -> 确认 -> 发货 -> 收货
      └─ 过程记录：试模 / 量产 / 模具评判 / 中止

物料管理
  ├─ 模具档案
  ├─ 工艺路线
  └─ 熔炼配方明细

材质牌号
  ├─ 熔炼配方
  └─ 设备允许材质

车间
  ├─ 产线
  ├─ 班组
  ├─ 设备
  ├─ 工艺路线工序
  └─ 动态排班

班次 + 班组 + 车间
  └─ 动态排班表

模具档案
  └─ 芯盒档案
```

## 后端与数据

后端已接入 PostgreSQL 和 Prisma，主要接口统一挂载在 `/api` 下。

主要能力：

- `/api/health`：健康检查
- `/api/auth/login`：管理端和小程序登录
- `/api/admin/departments`：部门管理
- `/api/admin/users`：用户管理
- `/api/admin/roles`：角色权限
- `/api/admin/customers`：客户管理
- `/api/admin/suppliers`：供应商管理
- `/api/admin/products`：物料管理
- `/api/admin/molds`：管理端模具开发
- `/api/admin/modeling/*`：生产建模与工艺管理
- `/api/mobile/home`：小程序首页
- `/api/mobile/todos`：小程序待办
- `/api/mobile/molds`：小程序模具开发任务

核心数据模型：

- Department
- User
- Role
- UserRole
- Customer
- Supplier
- Product
- MoldDevelopment
- MoldDevelopmentFlowRecord
- MoldProductionRecord
- Workshop
- ProductionLine
- Team
- MaterialGrade
- Furnace
- MeltRecipe
- MoldMaster
- CoreBoxMaster
- ProcessRouting
- ProcessRoutingStep
- ShiftMaster
- FactoryCalendar
- ShiftSchedule
- DefectCode
